# Kaptal Releases

Official public binary distribution and issue tracking repository for **Kaptal Desktop Application**.

- **Releases & Downloads:** https://github.com/vivhub/kaptal-releases/releases
- **Community Issue Tracker:** https://github.com/vivhub/kaptal-releases/issues

Production installers (`.exe`, `.dmg`, `.deb`, `.AppImage`) and Tauri auto-updater manifests (`latest.json`) are distributed here.

---

## How to Report an Issue

All user community issues, bug reports, and feedback should be reported here in **kaptal-releases**.

Whether you encountered a bug in the application, have questions about the version you are using, or ran into problems during download or installation, please open an issue in this repository:

👉 **[Report an Issue / Bug](https://github.com/vivhub/kaptal-releases/issues/new)**

### Types of Issues to Report Here
- **Application Bugs & Behavior**: Issues encountered while using Kaptal (UI glitches, calculations, portfolio tracking, bank/CSV statement imports, PIN lock, etc.).
- **Version-Specific Inquiries**: Behavior tied to the specific version/tag you have installed (e.g., `v0.1.0`).
- **Downloads, Installers & Setup**: Broken downloads, installation failures on Windows (`.exe` / `.msi`), macOS (`.dmg`), or Linux (`.deb` / `.AppImage`).
- **Auto-Updates & Integrity**: Issues applying in-app updates or validating cryptographic release signatures.
- **Feature Requests**: Proposals for new capabilities, supported brokers, or workflow improvements.

---

### Issue Report Checklist
To help us triage and resolve your report quickly, please include:
1. **Kaptal Version**: The version tag you are running (e.g., `v0.1.0` — found in Settings or application title).
2. **Operating System & Architecture**: e.g., Windows 11 (x64), macOS 14 Sonoma (Apple Silicon M2 / Intel), Ubuntu 24.04 (x64).
3. **Installation Type**: e.g., `.exe` installer, `.dmg`, `.deb`, `.AppImage`, or in-app auto-update.
4. **Steps to Reproduce**: The sequence of actions leading up to the issue.
5. **Expected vs. Actual Behavior**: What should have happened versus what occurred.
6. **Error Messages / Screenshots**: Any logs, console output, or error messages (please redact sensitive personal or financial information).
